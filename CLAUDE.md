&#x20;  # Rules for this Angular workspace



&#x20;  - Forms: always use Reactive Forms with typed form controls.

&#x20;    Do NOT use Signal Forms, even if the angular-developer skill suggests them.

&#x20;    They are still experimental in Angular 21.

&#x20;  - Design: use Angular Material only. Keep all screens consistent with the

&#x20;    existing Material theme. Do not add other UI libraries.

&#x20;  - This folder contains several projects. When building or testing, always

&#x20;    name the project, for example: ng build mss-invoice, ng test mss-invoice

&#x20;  - Never put calls to the server directly inside screen components.

&#x20;    Put them in a separate service file.
